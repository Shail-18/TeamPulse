# TeamPulse — Enterprise HR & Workforce Team Dynamics Platform

**TeamPulse** is a modern enterprise workforce management platform designed to connect People Operations (HR), Department Managers, Sprint Team Leads, and Staff Employees into a single, cohesive workspace.

---

## 🌟 Key Features

### 1. Role-Based Access Control & Tailored Portals
- **HR Admin Portal**: Company-wide oversight across departments. Manage employee records, assign unassigned new hires directly to teams, and review overall organization metrics.
- **Department Manager Portal**: Leadership view across department teams. Review Team Leads and Staff, approve PTO/leave requests, and manage department staffing.
- **Team Lead Portal**: Sprint and squad level management. Moderate peer kudos, view staff workloads, and support team execution.
- **Staff Employee Portal**: Individual self-service dashboard. Complete eNPS pulse surveys, send peer appreciation kudos, request leave, and track personal OKRs.

### 2. Smart Team Assignment Workflow
- Unassigned new hires are flagged automatically in the workspace.
- HR Admins and Managers can assign staff directly into appropriate department squads with strict role-based visibility rules.

### 3. Sentiment Pulse Surveys & eNPS Analytics
- Collect anonymous employee feedback to measure team sentiment.
- Real-time visualization of eNPS scores, participation trends, and workplace satisfaction indicators.

### 4. Peer Recognition & Kudos
- Send public shoutouts with core-value badges to celebrate wins across teams and foster a positive workplace culture.

### 5. Automated Leave & PTO Management
- Submit leave requests with automatic balance calculation.
- Streamlined approval flows for managers and department heads.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS
- **Icons**: Lucide React (`lucide-react`)
- **Backend & Database**: Firebase Firestore for persistent cloud data, Node.js / Express
- **Build System**: Vite & Esbuild

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/teampulse.git
   cd teampulse
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Start the production server:
   ```bash
   npm run start
   ```
